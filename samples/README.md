# samples/

Put your own Virus TI preset banks here (`.mid` exported from Virus Control /
Control Center, or `.syx`) to run the tools against them, e.g.:

```sh
python3 -I src/decode.py "samples/YourBank.mid"
```

**These files are deliberately git-ignored.** Commercial soundsets are copyrighted and
must not be committed or redistributed. Only this README is tracked.
